# ArmDemo Engineering Log — 2026.8.9

## English

### Goals

- Build safe voltage control for the dual-motor arm using the integrated TalonFX encoders.
- Calibrate the arm's 0–90 degree travel and expose its status in AdvantageScope.
- Configure the final controller bindings for the arm and elevator.
- Add an elevator subsystem with encoder zeroing, independent travel limits, and automatic movement commands.

### Completed Work

- Configured the arm's two Kraken X60 motors on CAN IDs 1 and 2 in Brake mode.
- Added startup zeroing for both arm encoders and averaged their positions for arm angle measurement.
- Calibrated 90 degrees of arm travel to `0.2` motor rotations and enforced software limits from 0 to 90 degrees.
- Added adjustable arm voltage through NetworkTables with a default of `3V` and a maximum of `6V`.
- Added AdvantageScope telemetry for arm angle, encoder positions, calibration state, limit state, requested voltage, and applied voltage.
- Removed the remaining example subsystem, example command, and autonomous template code.
- Corrected the raw controller mapping so button 4 raises the arm and button 2 lowers the arm.
- Added `ElevatorSubsystem` for two Kraken X60 motors on CAN IDs 11 and 12, both configured in Brake mode.
- Added startup zeroing for both elevator encoders and preserved separate measurements because the two mechanisms have different travel ratios.
- Corrected both elevator encoder directions so extension is displayed as a positive value in AdvantageScope.
- Set independent elevator upper limits of `3.4` rotations for motor 1 and `14.5` rotations for motor 2; reaching either limit stops both motors.
- Added a zero-position lower limit so reaching either lower limit stops both elevator motors.
- Set elevator movement to opposing `3V` outputs: motor 1 and motor 2 receive opposite voltage signs in each direction.
- Configured button 3 to extend the elevator and button 1 to retract it; one press runs the command until a limit is reached.
- Added automated subsystem tests covering encoder zeroing, direction normalization, voltage direction, and independent upper and lower limits.
- Removed generated build artifacts and caches from repository tracking and resolved the duplicate generated-file build failure.

## 中文

### 今日目标

- 使用 TalonFX 内置编码器为双电机机械臂实现安全的电压控制。
- 标定机械臂 0–90 度行程，并在 AdvantageScope 中显示运行状态。
- 配置机械臂和 Elevator 的最终手柄按键绑定。
- 新增 Elevator 子系统，实现编码器归零、独立行程限位和自动运动命令。

### 已完成工作

- 将机械臂的两个 Kraken X60 电机配置为 CAN ID 1 和 2，并设置为 Brake 模式。
- 添加机械臂两个编码器的启动归零，并使用两者平均位置计算机械臂角度。
- 将机械臂 90 度行程标定为 `0.2` 电机圈数，并加入 0–90 度软件限位。
- 通过 NetworkTables 添加可调机械臂电压，默认值为 `3V`，最大值为 `6V`。
- 在 AdvantageScope 中添加机械臂角度、编码器位置、标定状态、限位状态、请求电压和实际输出电压遥测。
- 删除残留的示例 Subsystem、示例 Command 和自动阶段模板代码。
- 修正手柄原始按键映射：按键 4 控制机械臂上升，按键 2 控制机械臂下降。
- 新增 `ElevatorSubsystem`，使用 CAN ID 11 和 12 的两个 Kraken X60 电机，并全部设置为 Brake 模式。
- 添加 Elevator 两个编码器的启动归零；由于两个机构的行程比例不同，保留两个独立测量值，不再计算平均值。
- 修正两个 Elevator 编码器的方向，使伸出时在 AdvantageScope 中显示为正值。
- 设置独立上限：电机 1 为 `3.4` 圈，电机 2 为 `14.5` 圈；任一电机到达上限都会让两台电机同时停止。
- 添加零位下限，任一电机到达下限都会让两台 Elevator 电机同时停止。
- 将 Elevator 运动电压设为方向相反的 `3V` 输出，两台电机在每个运动方向上接收相反符号的电压。
- 设置按键 3 控制 Elevator 伸出、按键 1 控制 Elevator 收回；按一次后命令持续运行直到达到限位。
- 添加子系统自动化测试，覆盖编码器归零、方向修正、电压方向以及独立上下限。
- 清理仓库中的编译产物和缓存，并解决重复生成文件导致的构建失败。
